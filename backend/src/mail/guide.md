Mail (sous-module de la Messagerie) : la boîte Gmail du club, dans Messages, puce « Mail » à côté
de « Chat ». Éteint par défaut : l'Administrateur principal le coche dans Admin › École ›
Personnalisation › Fonctionnalités, ligne Mail sous Messagerie.

Qui le voit
- Seulement les personnes du groupe 🔒 « Boîte mail du club » (Admin › École › Administrateurs,
  Groupes). Les autres voient Messages comme avant, sans puce.
- Je ne lis pas les mails du club : je peux seulement dire où aller.

Connecter la boîte (Messages › Mail, la première fois)
- Seul l'Administrateur principal (qui a le droit) la connecte ; les autres voient « La boîte mail
  du club n'est pas encore connectée. »
- Adresse Gmail du club, puis « Ouvrir Google » : sur la page Google des mots de passe des
  applications, appuyer sur Créer et copier le code de 16 lettres. Il faut la validation en deux
  étapes sur le compte Google.
- Revenir, « Coller », puis « Connecter ». « Code refusé » : recoller le code en entier ou en créer
  un nouveau.
- Menu ⋮ de la boîte : l'adresse connectée et « Déconnecter la boîte » (Annuler pendant 10 s).
