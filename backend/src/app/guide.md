Barre du bas : Admin, puis les onglets des modules allumés (Présence, Chorégraphies, Messages, Docs,
Financier, Fights), Supervision, Profil. Chacun ne voit que les onglets de ses rôles. Sur téléphone,
les derniers passent sous « Plus » (⋯) en bas à droite ; le badge des messages non lus s'y ajoute.

En-tête
- Bulle à gauche du badge : ouvre ou ferme l'assistant (absente si le module Assistant est éteint).
- Badge aux initiales : la personne connectée. Son menu liste les autres profils de la même adresse
  (passer à un profil plus élevé redemande le mot de passe) et « Se déconnecter ».
- Menu ⋮ à droite du badge : les actions de l'écran ouvert (Admin › École, Admin › Élèves…).
- Bandeau « Activer » : autoriser les notifications sur cet appareil.
- Ancienne saison affichée : bandeau « Saison … : consultation, lecture seule » et bouton
  « Revenir à la saison courante ».

Admin (admins) : quatre sous-onglets École, Élèves (avec le nombre), Profs, Cours. Ces quatre mots
peuvent être changés par l'école (Vocabulaire).

Admin › École
- Menu ⋮ « Menu École » : Sauvegarder École ; Programmer sauvegarde École ; Télécharger les nouveaux
  inscrits ; Importer sauvegarde ; Intégrer fichier élèves officiel ; Ajouter un administrateur
  (administrateur principal et Super User) ; Supprimer Données École (taper le nom de l'école).
- Volets à déplier : Coordonnées (nom, code postal, adresse, ville, SIRET, IBAN, mail de contact,
  mail de la trésorerie, qui reçoit les notes de frais).
- Saisons (caché si le module Saisons est éteint) : « Saison affichée » pour consulter une ancienne
  saison ; Créer une saison ; Éditer la saison ; Supprimer une saison (taper son nom) ;
  « Ouvrir aux modifications » / « Refermer la saison » sur une ancienne saison (administrateur
  principal et Super User).
- Créer une saison : un seul écran prérempli, nom et dates, puis une ligne par partie (structure
  des élèves « Regarder… », élèves, profs, cours, documents « Changer… »), puis « Créer la saison ».
- Tarifs : Formules (« + Ajouter une formule ») et « Options et codes promo » ; dans une formule :
  échéances, « Proposée cette saison », Dupliquer, Retirer ; en bas « Valider les tarifs ».
  Saison neuve : « Reprendre ceux de <saison précédente> ».
- Administrateurs : tableau Nom, Prénom, Email, Administrateur principal, Groupes, Inviter, Statut.
  Toucher la case Groupes : Bureau (Président·e, Vice-président·e, Secrétaire, Trésorier·e), Profs,
  groupes de l'école, 🔒 Accès au Financier, « + Nouveau groupe… ». Crayon et poubelle :
  administrateur principal, jamais sur sa propre ligne.
- Personnalisation de l'application : Apparence visuelle (aperçus, adresse web de l'appli, nom sous
  l'icône, logo, nom de l'école en texte ou image, slogan, polices, couleurs ; Enregistrer ;
  « Revenir à l'apparence par défaut »), Fonctionnalités (une case par module), Vocabulaire.
- Usage des ressources : Mémoire (disque, les plus grosses vidéos, poubelle) ; dépenses de
  l'assistant, avec « Changer le plafond mensuel ».

Admin › Élèves
- Recherche par nom. Toucher un nom, une cellule ou le paiement : la fiche de l'élève.
- Bandeau « X a deux fiches » (même prénom et nom qu'une autre fiche, élève, prof ou admin) :
  bouton Fusionner, l'autre fiche est déjà choisie, puis « Quel mail garder ? » (cocher le bon).
- Appui long sur une cellule : la voir en entier, « Copier dans le presse-papier », marquer la
  cellule ou toute la ligne en rouge.
- Colonne Inviter : « Inviter » / « Réinviter », en tête « Inviter tous les non-invités ».
- « + » en bas : ajouter un élève ; icône dossier : Intégrer fichier élèves officiel (.csv, .xlsx).
- Menu ⋮ : Inscription élève (OCR) (2 photos par fiche, recto verso) ; Inscription élève (web) ;
  Champs : « La fiche d'un membre » (« + Ajouter un champ », « Affichage dans Admin › » pour
  choisir et ordonner les colonnes).
- Fiche : Modifier, puis Valider ou Annuler ; « Fusionner avec… » pour réunir deux fiches.

Admin › Profs
- Recherche ; toucher les cours enseignés pour les cocher ; Inviter, Statut.
- Icône calculette : relevé d'heures (période, heures normales et sup) ; crayon ; poubelle ; « + ».

Admin › Cours
- Menu ⋮ près de la recherche : Ajouter un nouveau cours ; Planning hebdomadaire (semaine en
  grille, « Afficher le nom du prof »).
- Poignée pour réordonner ; toucher les élèves pour la liste ; crayon, poubelle ; « + ».
- Un cours : nom, jour (« + » pour un autre jour), horaires, salle, discipline, niveau, professeur,
  « Créer aussi la conversation de groupe de ce cours ».

Profil : identité (email et téléphone modifiables au crayon par un admin, sinon via Admin), Ma
famille, Mes heures (profs), Mes notes de frais, Notifications, Changer mon mot de passe, Mon RIB,
Changer d'école (Super User), Se déconnecter.

Supervision (Super User seulement) : vide pour l'instant.

Règles de l'appli
- Une personne = une seule fiche par école et par saison ; élève, prof, admin s'y cumulent. Deux
  fiches de la même personne se fusionnent (si l'une est admin : administrateur principal ou Super
  User seulement).
- Niveaux : Membre, Admin, Administrateur principal (gère les admins, les 🔒 et Fonctionnalités),
  Super User (toutes les écoles, choisit son école en arrivant). Toujours un administrateur
  principal par école ; personne n'agit sur sa propre ligne.
- Trésorier·e est un titre du Bureau ; le Financier s'ouvre par le groupe 🔒 Accès au Financier.
- Famille = les fiches qui ont le même email du payeur ; le parent bascule entre ses enfants.
- Les écoles sont étanches : un admin ne voit que la sienne.
- Seule la saison courante se modifie et se connecte ; les anciennes sont en lecture seule, sauf
  ouverte exceptionnellement (sans envoi de mails). Seuls les admins consultent une ancienne saison.
- Éteindre un module cache son onglet et ses actions sans rien effacer.
- Changer l'adresse web : administrateur principal ; les élèves doivent réinstaller l'appli.
